# 진행 일지

작업 날짜는 2026-08-18 ~ 2026-08-19. 스윙·중장기 매매 메모를 페이지로 만들고, 폰과 PC가 같은 기록을 쓰게 한 과정이다.

## 2026-08-18

### 메모를 페이지로

`매매.txt` 한 장으로 수익을 적고 있었다. 날짜·가격·보유일 쓰는 법이 거래마다 달랐다. 종목 한 건이 아니라 **매매 한 회차**를 기준으로 정리하기로 했다.

연도는 2026년으로 두고, 가격이 없는 건은 비웠다. `메도`→매도, `분활`→분할로 고쳤다. 아가방 `0629,5`는 앞 패턴대로 6/29 비중 5로 봤다.

첫 결과물은 루트 `index.html`이다. 브라우저에서 바로 열리는 한 장짜리 페이지로 시작했다.

### 계좌, 총수익, 추가·수정, 핸드폰

총 수익률(건당 합), 계좌 `5624-1531`, 추가·수정을 넣었다. 수정 화면에서 삭제도 된다. 좁은 화면은 표 대신 카드다. 기록은 처음엔 **그 브라우저 localStorage**에만 남았다.

### 작업 원칙

`README.md`의 네 가지를 이후 기준으로 두었다. 생각 먼저, 요청한 것만, 필요한 곳만 고치고, 확인될 때까지 한다.

### 월별 매매

월별 막대가 커서 줄였다. 이름은 **월별 매매 기준**으로 바꿨다. 달마다 건수·합계·평균·최고를 넣고, 총 수익률 옆에 **월별평균**(총합 ÷ 매도월 수)을 넣었다. 달은 **매도일** 기준이다.

그다음 달을 누르면 그달 종목·기간·수익률이 펼쳐지게 했다. 수익률 높은 순이다. 종목을 누르면 수정이 열린다.

### 기록이 안 보이던 날

`Esc`로 창 닫기를 넣으면서 저장 함수가 깨졌다. 스크립트가 멈춰 화면이 비었다. 저장 함수를 다시 붙였다.

### 보유일

보유일은 입력하지 않는다. **매도일 − 매수일**로만 계산한다.

### 공유가 되는지

페이지에서 고쳐도 `매매.txt`는 안 바뀐다. 폰과 PC도 브라우저가 달라서 기록이 안 맞았다. Vercel에 페이지만 올리면 주소로 열 수는 있어도, 저장소가 없으면 공유는 안 된다.

### GitHub

https://github.com/blugol/project_stockRecord 에 처음 올렸다. 이후 기능은 `main`에 커밋하고 푸시한다.

## 2026-08-19

### Vercel + Upstash

Vercel 배포: https://project-stock-record-ox8q.vercel.app

정적 페이지만으로는 기기가 안 맞아서 `/api/trades`를 붙였다. 저장은 **Upstash Redis (Free)** 다.

만든 DB: `upstash-kv-aureolin-island`. 지역은 Washington D.C. East, Read Regions 없음, Eviction 끔.

연결만 하고 재배포를 안 하면 API가 `KV is not connected`를 냈다. Connect 후 Redeploy 하니 200으로 매매 17건이 나왔다. 폰·PC 추가 테스트가 됐다.

서버가 원본이다. `매매.txt`를 저장할 때마다 GitHub에 쓰는 방식은 쓰지 않기로 했다.

### txt 내보내기

PC에서 **매매.txt 저장**을 누르면 현재 전체 기록을 같은 파일에 덮어쓴다. 새 `매매 (1).txt`를 계속 만들지 않는다. Chrome/Edge의 파일 지정 API를 쓰고, 안 되면 다운로드로 떨어진다.

### 문서·폴더 정리

진행 일지, 기술 스택, 코드 구조를 `docs/`에 나누고, 원본 메모는 `data/매매.txt`로 옮겼다.
