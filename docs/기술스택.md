# 기술 스택

빌드 도구 없는 정적 페이지 + 서버리스 API다. React, Next.js, npm 패키지는 쓰지 않는다.

## 프론트

| 항목 | 선택 |
|------|------|
| 페이지 | `index.html` 한 장 |
| 언어 | HTML, CSS, JavaScript |
| 폰트 | Pretendard (CDN) |
| 화면 | 데스크톱 표 / 모바일 카드 |

프레임워크를 안 쓴 이유: 더블클릭이나 Vercel 주소만으로 열리게 하려고.

## 저장

| 단계 | 어디 |
|------|------|
| 원본 | Upstash Redis. 키 `stockRecord:trades` |
| 연결 | Vercel Serverless `api/trades.js` → `GET` / `PUT` |
| 환경 변수 | `KV_REST_API_URL`, `KV_REST_API_TOKEN` (또는 Upstash REST 이름) |
| 보조 | 브라우저 `localStorage` (`stockRecord.trades.v1`). API가 없을 때만 |
| 메모 원본 | `data/매매.txt`. 앱이 자동으로 고치지 않음 |
| PC 백업 | 같은 `매매.txt`에 전체 목록을 덮어씀 |

폰과 PC가 맞춰지는 조건: Upstash가 프로젝트에 연결되고, 그 상태로 Redeploy된 배포를 쓸 때.

## 쓰지 않은 것

- Next.js / React (Upstash 퀵스타트 예제는 무시)
- `@upstash/redis` SDK (REST `fetch`만 사용)
- `매매.txt`를 커밋으로 자동 갱신
